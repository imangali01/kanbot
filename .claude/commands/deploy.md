Задеплой kanbot на Vercel строго по инструкции [docs/deploy-vercel.md](../../docs/deploy-vercel.md).

1. Прочитай `docs/deploy-vercel.md`.
2. Если менялась схема БД, сначала накати миграцию (`npm run db:migrate`).
3. Убедись, что `npm test`, `npm run typecheck` и `npm run build` проходят, а изменения закоммичены и запушены в `main`.
4. Выполни из корня проекта команду из инструкции (токен берётся из `~/.vercel-token`, в чат и файлы его не копировать).
5. Проверь, что прод обновился (маршрут из инструкции отвечает 401, а не 404), и сообщи адрес https://kanbot-ruby.vercel.app и результат.

Если режим разрешений блокирует прод-деплой, не обходи блокировку: объясни пользователю и дай команду для запуска самому.
